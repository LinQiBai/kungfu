# 八段锦动作识别与标准度打分

基于 **MediaPipe** 人体姿态估计与 **PyQt5** 图形界面的桌面应用，可对八段锦八式进行自动识别，并对动作标准度进行评分与改进建议。

## 功能特性

- **动作识别**：从摄像头或图片中检测人体骨架，自动判断当前最接近的八段锦式别
- **标准度打分**：按关节角度、对称性、稳定性等维度计算综合得分与等级
- **多种输入方式**：实时摄像头预览、抓拍分析、本地图片导入
- **实时骨架叠加**：可选在预览画面上显示姿态关键点
- **指定式别评分**：可手动选择某一式进行打分（不依赖自动识别结果）
- **改进建议**：根据分项得分给出针对性练习提示

## 技术栈

| 组件 | 用途 |
|------|------|
| [MediaPipe Pose](https://developers.google.com/mediapipe/solutions/vision/pose_landmarker) | 33 点人体关键点检测 |
| OpenCV | 摄像头与图像处理 |
| PyQt5 | 桌面 GUI |
| NumPy | 特征计算与相似度评分 |

## 项目结构

```
├── main.py              # 程序入口
├── config.py            # 识别阈值、评分权重、姿态模型参数
├── requirements.txt     # Python 依赖
├── run.bat              # Windows 启动脚本（需 conda 环境 gongfa）
├── core/
│   ├── pose_utils.py    # MediaPipe 姿态检测封装
│   ├── features.py      # 从关键点提取角度/高度等特征
│   ├── templates.py     # 八式标准模板与容差
│   ├── recognizer.py    # 式别识别
│   ├── scorer.py        # 标准度打分与反馈
│   └── analyzer.py      # 检测 + 识别 + 打分统一入口
└── gui/
    ├── main_window.py   # 主界面
    ├── workers.py       # 后台分析线程
    └── utils.py         # 图像格式转换等工具
```

## 环境要求

- Python 3.8+
- 摄像头（可选，用于实时预览与抓拍）
- 建议使用独立 conda 环境（见 `run.bat` 中的 `gongfa`）

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

**方式一：命令行**

```bash
python main.py
```

**方式二：Windows 批处理**

双击 `run.bat`（需已创建并激活名为 `gongfa` 的 conda 环境）。

### 3. 基本使用

1. 点击 **「开启摄像头」** 开始预览（或 **「打开图片」** 分析静态图）
2. 全身入镜、光线充足、背景尽量简洁
3. 保持目标动作后点击 **「抓拍分析」**，或开启 **「实时骨架」** 辅助观察
4. 右侧查看识别式别、置信度、综合得分、分项得分与改进建议
5. 下拉 **「指定式别」** 可固定某一式进行评分（选「自动识别」则按识别结果打分）

## 配置说明

在 `config.py` 中可调整：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `POSE_MODEL_COMPLEXITY` | MediaPipe 模型复杂度（0–2） | `1` |
| `POSE_MIN_DETECTION_CONFIDENCE` | 检测置信度下限 | `0.5` |
| `POSE_MIN_TRACKING_CONFIDENCE` | 跟踪置信度下限 | `0.5` |
| `RECOGNITION_THRESHOLD` | 判定「识别成功」的置信度阈值 | `0.55` |
| `SCORE_WEIGHTS` | 评分权重：角度 / 对称 / 稳定 | `0.7 / 0.15 / 0.15` |

## 使用建议

- 拍摄时尽量 **全身入镜**，侧身或遮挡过多会导致检测失败
- 穿与背景对比明显的服装，避免强光逆光
- 自动识别依赖与标准模板的特征距离；动作不标准时可能识别为相近式别，可手动指定式别再评分
- 评分结果仅供练习参考，不能替代专业武术指导
